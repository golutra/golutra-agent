# Golutra Docs

## 推荐阅读顺序

1. `ARCHITECTURE.md`：主架构规格，作为实现时的架构真相。
2. `implementation-blueprint.md`：第一阶段实现蓝图、最小 schema、同步/后台/离线边界。
3. `runtime-contracts.md`：runtime 硬契约，包括 tool/provider/terminal/cancel/retry/fallback。
4. `artifact-evidence-ledger.md`：artifact 和 evidence 的事实层规格。
5. `benchmark-hardening.md`：benchmark 防污染、防跑分和元数据要求。
6. `agent-runtime-technology-selection.md`：语言、crate、workspace 和库选型。
7. `context-memory.md`：context、token、compaction、memory governance。
8. `evaluation-observability.md`：观测、验证、复盘、benchmark。
9. `agent-improvement-loop.md`：失败轨迹如何变成可验证、可回滚的 agent 改进。
10. `agent-open-endedness-design.md`：开放式探索、技能晋升和 Promotion Gate。
11. `framework-comparison.md`：六个外部 agent 项目对 Golutra 的影响。
