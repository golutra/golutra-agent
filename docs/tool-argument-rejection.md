# Shell 分页参数拒绝与诊断

## 当前合同（2026-09-17）

后续真实会话再次出现 `12000` / `20000` 超限，说明只在描述中补写 4096 上限仍会带来无效往返。现在 `max_output_bytes` 是可省略的软预览预算，默认及运行时上限为 12288 字节，最小仍为 256。更大请求封顶；错误类型、低于最小值等真实非法请求仍在执行前拒绝并显示脱敏诊断。这是显式修改接口合同，不是偷偷修正旧合同中的非法调用。

同时增加 `shell_session(action=read)`，立即返回已产生输出。退出后有剩余正文只产生可选续读，不再要求模型逐页读完；必要验证、完整读取要求和非零退出码照常保留。`read_file` 指引优先读取文件相关片段，替代组合 cat/sed 并强制读完整份说明的行为。详见 [后台终端](background-terminals.md)。

成本：单次 shell 结果可携带更多正文；这是用适度更大的预览减少 provider 往返，并不保证所有任务的总 token 都下降。工具描述/schema 改动会更新 wire digest，已有缓存可能冷启动。

本轮回归覆盖：

- 约 23 KiB 的中文/emoji 输出，在默认、12000、20000 三种请求下均只需首次返回和一次续读即可完整恢复；断言针对最终 provider 投影正文。
- 上下文只允许 1 KiB 结果时，显式游标与小预算可持续前进并恢复全部保留内容。
- `read` 对仍在运行的进程立即返回；非零退出码即使正文未读完仍为失败。
- wait/read 对不同进程可并行，同进程交互、写入和终止边界保留。
- PTY + 本地 HTTP provider 捕获实际请求：12000/20000 合法预览无需参数纠错或额外分页；255 仍执行前拒绝，纠错后只执行合法命令。
- 已完成普通命令与后到终态事件合并，保持 `ran`；输出续读单独显示 `Read terminal output`。

上述是确定性本地回归，不等于真实上游模型的工具选择成功率或延迟基准。此次不据此宣称三方性能已经全面领先，也不把 `/status` 覆盖长回答的问题算作已修复。

本轮验证通过：tools 179 项、runtime 194 项、LLM 单元 89 项及 provider golden 23 项、TUI 库 18 项及主程序 373 项。紧预算完整恢复与最终界面标签另行定向复测通过。PTY 过滤集中的 4 项分别通过，其中新增软预算测试首次停在 guarded 审批页，补上测试内显式审批后通过。`cargo fmt --all -- --check`、四个相关 crate 的 `cargo clippy --locked --all-targets -- -D warnings` 和 `git diff --check` 均通过。测试配置、工作区和 HTTP provider 均隔离于真实用户数据。

下文记录上一轮诊断及验证，4096 硬上限不再是当前实现。

## 上一轮诊断

2026-09-16 排查会话 `01a0aa8d-7195-72d2-899a-cd584287dbc5`：第一次 `find` 调用传入 `max_output_bytes: 20000`，runtime schema 上限为 `4096`，因此在执行前拒绝。随后模型把同一命令的分页大小改为 `4096`，调用成功。

问题包含两层：provider 的精简 schema 投影移除了 `minimum/maximum`，原参数描述也没有写出范围，模型看不到执行边界；TUI 折叠卡片只显示 `tool request is invalid`，隐藏了诊断细节。这不是这次命令执行失败或网络失败的证据。

修复保持 provider schema 投影兼容策略和运行时限制，给 `shell`、`shell_session` 的分页参数描述明确标注 `256..4096` 字节、默认 `1024` 和续读方式。该描述随原有工具 wire digest 计算进入缓存身份。没有新增全局提示、自动截改参数、自动重试或隐式执行。

参数校验错误包含已声明的顶层字段名。只有上述内置工具的无符号分页数值可以原样显示；正文、路径和其他参数值仍脱敏。TUI 在折叠卡片及恢复历史中显示工具名与诊断，详情保留原有完整的有界错误。

回归覆盖：

- 上下界和错误类型诊断；字符串值继续脱敏。
- 三次独立重现超限请求：命令未执行；显式改为 `4096` 后只执行一次。
- 真实 PTY + 本地 HTTP provider：实际请求中的工具描述包含范围；拒绝原因进入下一轮模型输入；修正后的命令成功；终端无需展开详情即可看到原因。
- TUI 折叠、展开和历史投影都保留失败状态；已有错误卡片的通用语义不变。

上游模型仍可能生成非法参数。验收目标是边界对模型可见、无效调用不执行、诊断可纠正，不能用少量成功样本宣称错误概率为零。
