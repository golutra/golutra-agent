# Inline 聊天与全屏工具详情

交互入口 `golutra-agent` / `golutra-agent-tui` 默认使用普通终端上的 inline 聊天。Logo、用户问题、助手叙述、工具摘要和本地命令结果依次进入终端历史；活动输出与输入框留在 inline viewport。启动时不进入 alternate screen，旧 `--inline` 参数仅为兼容保留。

普通聊天关闭鼠标捕获，滚轮滚动、拖选和系统复制快捷键由终端处理。按 Ctrl+O 进入独立全屏工具详情；详情内支持鼠标操作，Back 或 Esc 返回后立即释放鼠标，保留草稿与主屏位置。已有 /resume 等选择器继续使用临时全屏交互。

`/auth` 认证向导保持全屏，但仅用方向键、数字键和 Enter 选择，Esc 返回上一步，PageUp/PageDown 滚动；不捕获鼠标，拖选和复制交给终端。全屏状态与鼠标捕获分别管理，认证页与帮助页切换、窗口缩放及终端挂起恢复都保持各自的鼠标策略。

`/model` 直接进入模型编辑框。编辑状态下 Esc 保留修改并返回设置列表；列表里上下选择，Enter 编辑模型或调整选项，Esc 应用设置并返回聊天，不需要 `e` 键。编辑时 Enter 或任意设置状态下 Ctrl+S 也可直接应用退出。Ctrl+U 清空输入；空值或超过 256 字符的模型名保持编辑状态并显示错误。这两个入口同样不捕获鼠标，文字选择和复制交给终端。已处于 unrestricted（包括 `--yolo`）时修改模型不重复确认权限；从 guarded 改为 unrestricted 才要求 Enter 确认；确认页按 Esc 保存其他设置并保留原权限。任务执行期间仍锁定运行时设置。

本地运行时，模型选择立即用于当前会话，并保存到 `$GOLUTRA_AGENT_HOME/runtime.json`，重启后继续使用；若项目已存在 `.golutra-agent/runtime.json`，则更新该项目层，避免旧的项目覆盖使模型还原。显式切换 profile 时同时保存对应选择。保存复用锁、revision 校验和原子文件替换，只修改模型相关字段，不改写凭据、provider 定义或权限；失败时保留编辑框及草稿，不假报成功。`/model <model-id>` 使用同一机制。远程 TUI 保持会话覆盖，不写本地配置冒充修改远程主机。

选择 `3 Custom Provider` 后，协议列表分别提供 `1 OpenAI Chat Completions`（`/chat/completions`）和 `2 OpenAI Responses`（`/responses`）。两者是独立协议，不自动互换；根据服务商支持的接口选择。Base URL 填 API 基础地址（例如 `https://api.openai.com/v1`），不附加 `/responses` 或 `/chat/completions`。保存前探测凭据和模型列表，保存的协议决定后续生成请求使用的接口。

Reasoning effort 在设置页和认证高级配置中的顺序统一为 `default → low → medium → high → xhigh → max → ultra`，界面、配置和请求值均使用小写；`/effort max`、`/effort ultra` 同样可用。Responses 和 Chat Completions 按显式选择发送原值，具体模型是否接受由上游决定。`ultra` 是网关扩展，当前 Genai 原生适配器不支持时明确报错，不自动降档；`max` 在其他原生协议中沿用依赖库的协议映射。

输入 `/` 时，在输入区显示最多 5 个常用命令及简短说明：`/help`、`/model`、`/resume`、`/status`、`/new`。继续输入按前缀筛选；方向键选择，Tab 仅补全，Enter 执行或进入参数填写。第一次 Esc 收起候选并保留草稿，不中断正在运行的任务；继续编辑会重新筛选。普通命令进入参数填写后不再显示命令名候选，`/auth` 与 `/debug` 支持子命令补全。

候选高度按实际描述换行计入 inline 活动区，显示预算为 8 行；普通命令仍最多提供 5 个候选。候选与普通模型/工作区底栏共享空间，打开时底栏替换为选择、补全、确认和关闭提示。小窗口优先保留输入与操作提示，候选窗口包含选中命令开头。测量与绘制共用 `CompletionPopupLayout` 的物理行。命令候选完全在本地生成，不请求模型。

主屏活动区从当前顶部锚点向下增长；空间不足时才通过原生滚屏将历史上推。候选过滤、Esc 收起及多行草稿缩短后保留顶部锚点，不反向下移历史、不强制贴底。暂时空出的空间由新内容自然消耗。这一规则同样适用于极小窗口，避免历史和下一条消息之间出现人为填充的空白。

## 架构

| 层 | 实现 | 职责 |
| --- | --- | --- |
| 持久历史 | `history_source.rs`、runtime store | 分页读取真实事件；恢复与交互共享 32,768 事件 / 32 MiB 预算 |
| 语义投影 | `transcript_view.rs` | 保留叙述与工具顺序，合并相邻读取/列表/搜索，保留执行、修改、失败和已归档边界 |
| 主屏归档 | `inline_history.rs` | 原生历史只追加，稳定流式前缀提交，最终修订明确标记，不发送清空 scrollback 指令 |
| 可见历史 | `resize_visible_history` | 只缓存一屏应用行，物理窗口缩放时重画可见区域；候选扩缩不触发重放，保留 shell 前缀 |
| 终端视口 | `managed_terminal.rs` | 持有同一 Backend 和绘制缓冲区，统一活动区扩缩、历史插入和临时全屏定位；仅启动时查询光标 |
| 工具详情 | `tool_detail.rs`、`transcript_interaction.rs` | 选中工具的独立详情、滚动、返回、显示单元格选择与复制 |
| 展示布局 | `transcript_widget.rs`、`render.rs`、`session_banner.rs` | 共享换行与语义渲染，响应式页首和活动区布局 |
| 终端生命周期 | `draw_interactive_frame`、`OverlayScreenState`、`terminal_integration.rs` | 同步归档/绘制，保存主屏 viewport，临时切换备用屏，退出和异常恢复 |

归档正文与行身份事务性提交，写入失败时不推进归档游标。工具摘要是否简洁由独立展示策略控制，不依赖是否全屏。

主屏不再重建 Ratatui Terminal，也不通过恢复阶段屏蔽 `append_lines` 修正位置。管理层直接更新矩形和缓冲区，继续使用 Ratatui 控件、换行算法与已有连续宽字符 Backend。一次帧更新依次处理物理窗口变化、准备稳定归档、按剩余活动尾部调整高度、写入历史、绘制活动区，整个过程仍由 synchronized update 包围。活动区在滚动前清理，候选、草稿和旧输入框不会被当作历史提交。

启动命令和已有 shell 输出不属于应用的清理范围。回复完成、输入框收缩和同一会话的布局刷新不再清空并重放整个历史。已归档的屏外内容保留原显示版本；如果最终答案确实修订了已经输出的流式正文，追加带 Updated response 标记的完整修订版本，不能为了擦除旧版本而清空用户终端。新进程 resume 使用持久化的最终事件。

启动横幅紧接 shell 输出，即使编译日志已经把光标推到屏幕底部，也不在 Logo 前补满一屏空行。归档通过自然滚屏腾出空间，不人为添加页首填充。

长代码块完成时，先准备待归档正文和提交标记，再按剩余活动尾部调整视口，最后插入历史。不能先为已完成正文保留整屏活动区、归档后才收缩，否则整段正文会被挤到屏外，下一条消息前留下整屏空白。标记与本地命令仍在同一事务内，终端操作失败时回滚。

详情页复用真实工具投影与已有的脱敏、输出预览上限，不额外调用模型生成标题。运行中工具进入详情后保留身份边界，完成事件可以更新同一页面。详情期间继续接收 runtime 事件，但不向备用屏写入主聊天历史；返回时统一归档未显示内容。

## 工具分组与显示

- 相邻成功的读取、列目录、搜索可以合并；助手叙述、shell、文件修改、后台交互和失败保持各自边界。
- 混合的上层 ToolBatch 摘要不能覆盖真实工具事件中的失败或执行边界。
- 简洁摘要保留类型、状态和少量对象/命令预览，按显示宽度限制长命令；单文件读取不重复打印标题中已有的文件名。
- `Ctrl+O` 打开最近一个工具的全屏详情；左右方向键或详情页 Prev/Next 按钮查看较早/较新的工具。
- 普通聊天与认证向导不拦截单击和拖选。其他支持鼠标交互的临时全屏页面按需捕获鼠标，返回不会把原聊天中的所有工具展开。
- 详情展示已脱敏的调用信息与有界结果，失败信息不因其他调用成功而隐藏；不等于无界完整日志。
- 参数校验失败在主聊天和恢复的历史中显示 `Failed · <tool>` 与具体诊断，例如 `max_output_bytes: 20000 is greater than the maximum of 4096`；完整的有界诊断保留在详情和原始事件中。只展示 schema 已声明的顶层字段名，以及 shell 分页大小这一非敏感数值，其他参数值继续脱敏。工具请求仍被拒绝，不自动修改参数或执行失败的请求。
- 独立消息间保留一行空白，正文原有段落空行继续保留。

工具显示策略不改变实际工具次数、执行顺序、权限、失败语义或模型可见结果。模型设置的持久化仅保存用户显式选择，不改变 provider 协议或凭据。

## 滚动、复制与返回

- 主聊天支持原生滚轮、拖选与终端复制，无需额外 Shift 旁路；不会用全程鼠标捕获换取摘要点击。
- 启动、全屏页面返回和外部终端挂起/恢复均保持主聊天鼠标捕获关闭。
- 详情页支持鼠标滚轮、方向键、PageUp/PageDown、Home/End；默认从顶部查看，新结果不会主动推走阅读位置。
- 详情页鼠标拖选按显示单元格处理中文、emoji 和续格；内容或尺寸变化时清除过期选区。
- 详情中 Alt+C / Ctrl+C 复制选区，无选区时复制有界详情正文。沿用 OSC52 和 100 KiB UTF-8 安全截断，需要终端支持。
- 详情中的普通输入和粘贴不会写入隐藏的聊天草稿。Esc / Back 只关闭详情，不中断后台执行。
- 本地 /status 属于当前界面记录；新进程 resume 恢复持久化 runtime 对话，不声称恢复未持久化的本地状态面板。
