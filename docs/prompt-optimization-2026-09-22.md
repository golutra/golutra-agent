## 真实模型实验

环境：macOS ARM64，本机 debug 原生二进制，`anthropic` 协议、`cd-fable-5.1`，使用现有配置的同一网关。每次运行使用独立工作区与私有临时凭据目录；没有修改全局配置。模型名称来自网关配置，不推断网关背后的模型身份。

首轮在 2026-09-22 22:07–22:12（北京时间）交替运行基线与中间候选，各三个任务、每项两次。两个版本均为 **4/6**：只读分析数值正确且没有改文件，但都在用户要求的 JSON 外添加 Markdown 围栏，判为失败；注释修改和子目录约定均通过。未删除失败样本，也未放宽 JSON 验收。

在最终提示中补充通用规则：用户要求精确格式时只输出该格式、不增加标记。增加此前未参与调整的 CSV 任务，再于 22:14–22:16 运行最终版本复测。没有针对文件名、数值或某个模型写生产特判。

| 任务 | 基线首轮 | 中间候选首轮 | 最终版本复测 |
| --- | --- | --- | --- |
| 只分析、不改文件、精确 JSON | 0/2 | 0/2 | 2/2 |
| 只翻译注释、保留代码和用户草稿 | 2/2 | 2/2 | 2/2 |
| 遵守子目录 AGENTS.md、实现并验证 | 2/2 | 2/2 | 2/2 |
| 精确 CSV、不改文件（新增迁移任务） | 未运行 | 未运行 | 2/2 |

最终 **8/8** 通过。判题检查真实产物和最终回答，运行时报告成功本身不算通过。JSON 与注释检查不依赖模型自称“没有修改”，子目录任务另行运行独立计算验收。工具次数仅作观察，不限制模型如何完成工作。

最终复测只有最终二进制，不是新的配对时延实验；首轮部分候选尝试也比基线更慢。因此本轮不报告提速百分比。全部时间、请求数、工具数与失败回答保留在 JSON 记录中。

复测入口（替换为已冻结的原生二进制绝对路径）：

```sh
python3 scripts/compare_generalization.py --configured-provider \
  --variant final=/absolute/path/to/golutra-agent \
  --task analysis_scope --task comment_scope --task nested_rules --task csv_scope \
  --repeats 2 --timeout 180 --output /tmp/prompt-behavior-results.json
```

`--configured-provider` 保留源配置的协议、模型、地址与生成设置；此模式不支持直接加入 Codex。比较时需冻结配置和二进制，保持任务 digest 一致。`--timeout` 是评测进程的超时，不是产品新增的长任务限制。
