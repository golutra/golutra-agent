# Agent 提示与上下文合同

本轮以 `7cc1e9c` 为基线，收敛模型收到的行为规则与真实运行时能力。模型负责按任务判断，运行时负责权限、工具结果、取消、预算和验证事实；不新增监督模型、固定任务轮数或每阶段固定检查表。

## 核心行为

`client/src/context.rs::system_prompt` 定义共同原则：分析和审阅不隐含修改授权；实施持续到交付和相关验证。尚未完成的用户要求及有效约束跨回合、压缩保留，后续用户修改取代冲突的旧要求。工具输出、引用、记忆和助手声明不提供新的授权。

读取足以理解变更的上下文，按影响选择测试和调用方；保留用户无关修改。独立工作可批量进行，依赖操作等待前置结果。相关修改保持一致，原子补丁是适用时的选择。可信写入结果不要求机械回读；发生新变化、失败或未解决疑问时才扩大验证。用户要求及相关检查满足后结束。

开始实质工作时简要说明，进展更新只表达新发现、方向变化或长等待；不强制每批工具前叙述。使用用户语言，严格输出格式不增加代码围栏等额外标记。文件工具优先但不禁止有理由的 Shell 组合读取。

## 指令来源

系统与环境、已加载项目指令属于稳定前缀；历史、记忆、当前目标、可选技能和输出 schema 属于动态上下文。子代理独立角色、压缩来源校验、原始用户要求保留和 Handoff 边界继续复用现有实现。

项目启动只加载工作区及其祖先的 `AGENTS.md`，到仓库边界停止。每份内容带路径与作用目录，路径和内容转义防止破坏包装边界。深层规则只在对应目录生效，并优先于上层规则；显式用户要求与运行时安全边界优先。进入子目录前由模型通过现有工具发现并读取局部规则，不递归预加载全仓库，也不宣称宿主强制执行所有自然语言规则。

已安装技能沿用现有相关性选择与缓存。动态段提供完整的描述、作用域、前提、步骤及失败条件；不注入源轨迹，不再承诺没有入口的后续加载。按记忆与近期历史分配后的实际余额选择整份技能，超限跳过；显式 Trim 模式整体省略超限技能，避免保留步骤却切掉限制。未包含的技能不视为已经加载。

## 恢复与纠偏

长连接等待后的提醒追加为动态 user 消息，并在上下文来源中与真实用户要求区分。不能追加末尾 system 消息再让 genai 将其移动到静态前缀。各协议使用相同的来源边界，不修改重试、取消、工具副作用或历史配对语义。

纠偏动作依据已有检查与阻断断言类型生成，按同一检查的最新结果判断：

| 类型 | 动作 |
| --- | --- |
| 输出 schema | 修正最终回答；纯格式问题无需工具或工作区复验 |
| 交付或客观验证失败 | 修复相关问题，仅重跑受影响检查 |
| 缺少验证证据 | 补相关证据或说明无法验证，不断言测试已经失败 |
| 权限边界 | 说明限制，必要时请求授权，不重复被拒操作 |
| 混合失败 | 同时保留适用动作，不因格式修正掩盖真实交付失败 |

反馈不增加完成要求，Open/Strict、显式零次纠偏和独立验收边界保持原值。

## 验证方式

确定性测试检查实际上下文组装、完整技能预算、项目指令边界，以及真实执行循环中两次模型回答完成 schema 修正、零工具调用和零文件修改。原有多次压缩、用户补充、网络恢复、已完成副作用和交付验证回归继续执行。核心提示文本测试仅检查体积和分层，不用特定句子存在来证明模型行为。

HTTP/SSE 测试检查最终 wire 的系统内容与历史顺序，覆盖 Chat、Responses、Anthropic、Gemini、Vertex 的 Gemini/Claude 路由及 genai 原生路由，含流式和非流式。这些是受控协议测试，不是所有厂商云端实测。

`scripts/prompt_behavior_tasks.py` 提供只读分析、注释修改、子目录规则和独立 CSV 格式任务。判题检查真实文件、无关草稿、规则文件、计算结果和最终回答；不以工具数作为通过门槛。复用 `compare_generalization.py` 的冻结二进制、隔离数据目录和交替执行，`--configured-provider` 保留现有提供商协议、模型、地址及生成设置，避免把其他协议凭据发送到默认 Responses 地址。短任务结果不能证明多小时长任务或普遍性能优势。

本轮实跑与最终回归结果见[提示优化验收记录](prompt-optimization-2026-09-22.md)。
