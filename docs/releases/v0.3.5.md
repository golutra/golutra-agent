## Golutra Agent 0.3.5

This release improves terminal resizing, streaming history, code rendering and
large-paste editing while preserving native terminal text selection.

### Install or update

```sh
npm install -g @golutra/agent@0.3.5
golutra-agent --version
golutra-agent
```

### Terminal improvements

- Narrow-to-wide resizing reconstructs the banner and history at the current width.
  Drafts and local commands are retained; large histories load their full source
  before replay. Reconstructing native scrollback clears earlier terminal scrollback,
  including shell output preceding this session.
- Corrected final replies replace earlier streamed content without an extra
  "Updated response" copy. Removing a trailing newline alone does not rebuild history.
- Complete lines of long code fences enter scrollback before the fence closes.
- Small streaming updates are coalesced, with faster refreshes under backlog.
  Keyboard input, first content and completion keep their fast path.
- Command previews show both the beginning and the end of output with an omitted
  line count. Ctrl+O continues to open saved details.
- Large pastes display compactly while the original text is preserved for submission,
  editing and undo. Moving the cursor inside a paste expands it for editing.
- Syntax highlighting tracks multiline strings and comments by language and reuses
  parser state. Unknown languages and oversized blocks fall back to plain text.
- Diff backgrounds adapt to terminal lightness and color depth. Local Markdown
  links use concise workspace paths with line numbers and avoid duplicate labels.
  Explicit OSC 8 hyperlinks are not included.

### Distribution and validation

The npm launcher, six platform packages and native desktop archives share version
0.3.5. Native artifacts reuse the npm binary payloads. No data namespace or storage
schema change is included.

Local validation passed 503 TUI/library/driver tests, including 34 real macOS PTY
tests. One opt-in live-provider test was skipped. Clippy with warnings denied and
formatting checks passed. Release automation verifies six-platform packaging,
npm/native payload parity, offline startup and shared-data behavior before publishing.
These checks do not establish identical behavior in every terminal or against every
upstream provider.
