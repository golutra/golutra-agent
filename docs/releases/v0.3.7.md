## Golutra Agent 0.3.7

This release fixes Windows console mode initialization and restoration and
simplifies the official provider setup flow.

### Install or update

```sh
npm install -g @golutra/agent@0.3.7
golutra-agent --version
golutra-agent
```

### Changes

- Windows terminal setup records the console mouse-mode baseline before cleanup.
  Exiting or suspending the TUI restores cooked input after mouse cleanup so the
  parent shell and external editor receive the intended console mode.
- Selecting Golutra API opens API key entry immediately. Its built-in base
  address is `https://api.golutra.cn`; review and saving resolve the protocol path.
  Esc from the API key or environment variable screen returns to provider selection.
  The official preset continues to use OpenAI Chat Completions; protocol
  auto-detection is not included.
- The canonical repository retains the complete development commit history.

### Distribution and validation

The npm launcher, six platform packages and native desktop archives share version
0.3.7. Desktop archives and npm platform packages reuse the same native payloads.
No user-data format changes are included.

Local validation on macOS passed 41 terminal tests, 14 authentication dialog tests
and 39 packaging tests. All workspace targets compiled, and formatting and
repository metadata checks passed.

Release automation builds and runs package acceptance on Linux x64/arm64,
macOS x64/arm64 and Windows x64/arm64. It verifies npm startup, native offline
startup without Node/npm, shared-data behavior and npm/native payload parity.
The Windows package checks do not include interactive ConPTY acceptance; they
do not establish the console fix's behavior in every Windows terminal host.
