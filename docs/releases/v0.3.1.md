## Golutra Agent 0.3.1

This patch fixes custom-provider setup and API URL handling.

### Install or update

```sh
npm install -g @golutra/agent@0.3.1
golutra-agent --version
golutra-agent
```

### Fixes

- `/auth` and `/login` confirmation save locally and return to chat without a
  network probe. Failed saves remain visible in the setup dialog. Connectivity
  is checked by actual model requests, not claimed by an unperformed probe.
- Saving or switching a provider adopts its model and reasoning settings for
  the current session and after restart. Reusing the `custom` profile no longer
  combines a new protocol with a stale model override.
- Bare hosts automatically receive `/v1` for OpenAI Chat Completions, Responses
  and Anthropic, or `/v1beta` for Gemini. For example, an Anthropic configuration
  using `https://api.golutra.cn` requests `/v1/messages`, not `/messages`.
- Recognized full operation URLs are accepted without duplicating the suffix.
  Explicit API versions, proxy prefixes and ChatGPT backend paths are preserved.
  Existing configuration and environment-based setup use the same rules.
- Vertex AI still requires its project/location base path. Model-routed native
  providers use known protocol defaults or request an explicit API base path
  when a safe default cannot be determined.

### Distribution and validation

The npm launcher and six native platform packages use the same version and
native payloads as desktop archives: Windows, macOS and Linux, each on x64 and
ARM64. Desktop applications can bundle native archives without Node.js or npm.
The release inventory records source revision, download URLs and checksums.

The provider, configuration and authentication regression suite passed 195
checks before the version bump, including local HTTP request-path assertions,
offline setup, persistence and restart behavior. These checks do not establish
availability of any third-party model or API key. Release jobs additionally
require native execution, npm installation and shared-data acceptance on each
target OS/architecture before publication.

This patch does not change the storage schema or installation/data namespace.
The existing restrictions on obsolete data and concurrent ownership of a live
session remain in effect. npm manages npm installations; bundled desktop
payloads update with the desktop application.

See the [changelog](https://github.com/golutra/golutra-agent/blob/v0.3.1/CHANGELOG.md)
and [desktop integration guide](https://github.com/golutra/golutra-agent/blob/v0.3.1/docs/desktop-integration.md).
