## Golutra Agent 0.3.4

This release fixes duplicate streaming replies in Debug mode and makes the
timeline more compact while preserving complete events and native scrollback.

### Install or update

```sh
npm install -g @golutra/agent@0.3.4
golutra-agent --version
golutra-agent
```

### Terminal fixes

- Debug waits until both transcript and observation rows are stable before
  archiving them. Normal streaming no longer produces false "Updated response"
  notices. Genuine revisions of already archived text still remain visible.
- Live height follows the actual two-column wrapping, preventing the beginning
  of a reply from disappearing. A gutter separates the columns; diagnostic-only
  events no longer insert blank chat rows, and summaries wrap by word/grapheme.
- Esc dismisses root `/auth` and `/login` setup without repeated reopening.

### Debug navigation and history

- Complete history reloads in the background, can be cancelled, and merges new
  runtime events without replacing typed drafts. Total load caps are removed;
  memory use grows with complete history size, while archived active events
  remain reclaimable. Failed refreshes retain the last good snapshot.
- Alt+D opens redacted event details. Use Left/Right for events, Up/Down or
  PageUp/PageDown to scroll, Alt+C to copy, and Esc to return to the chat draft.
  Mouse selection remains controlled by the terminal.
- Tool counts and background-job states use stable identities. Archived facts
  are labelled as snapshots rather than implying live counters.
- `/debug switch` still toggles expanded summaries. All recorded events remain
  accessible; long open streaming blocks show their live tail and are archived
  in full once stable.

### Distribution and validation

The npm launcher and six native platform packages share version 0.3.4. Windows,
macOS and Linux x64/ARM64 desktop archives reuse the npm native payloads and
provide versioned URLs and checksums. Native startup needs neither Node.js nor
npm. No data namespace or storage schema change is included in this release.

Local validation passed 487 TUI/library/driver tests, including 30 real macOS
PTY tests, and 21 packaging-script tests. Clippy with warnings denied, formatting
and metadata checks passed. One opt-in live-provider test was skipped.
Coverage uses isolated
providers, including Debug before the first token, slow English/Chinese streams,
expanded/compact summaries, final-text uniqueness, resize, tables and genuine
revisions. Release jobs additionally require native launch, npm installation,
desktop offline launch, payload parity and shared-data checks on all six targets
before publication. These checks do not replace GUI desktop integration,
signing, real upstream-provider tests or every terminal/minimum OS combination.
