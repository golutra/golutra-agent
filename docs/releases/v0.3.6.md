## Golutra Agent 0.3.6

This release simplifies terminal conversations, improves task completion and
streaming projection, and fixes local service connections behind HTTP proxies.

### Install or update

```sh
npm install -g @golutra/agent@0.3.6
golutra-agent --version
golutra-agent
```

### Terminal and runtime improvements

- Verification records, residual risks and internal result assessments remain
  available in `/debug` without adding cards to ordinary conversations.
- A failed task displays one diagnostic at its original history position.
  Recovered provider errors do not leave a false failure notice.
- Streaming text and observational events reuse the current transcript projection;
  semantic changes still rebuild it to preserve correct replay.
- Tool previews remain compact, with complete saved details available via Ctrl+O.
- Startup no longer requests a background-color reply that can leak into input.
- Long-task recovery, compaction and completion evidence handling are improved.
  `/handoff` carries task context into a new conversation.
- Repeated correction cycles without new progress stop; missing evidence is
  distinguished from a check that actually failed.
- Loopback provider, model catalog, OAuth and app-server requests bypass HTTP
  proxies. Remote endpoints retain their normal proxy behavior.

### Distribution and validation

The npm launcher, six platform packages and native desktop archives share version
0.3.6. Desktop archives and npm platform packages reuse the same native payloads.

Local auth, client, provider and TUI validation passed 1,121 tests, including 35
real macOS ARM64 PTY tests. One optional live-provider test was skipped. Formatting
and Clippy checks passed. Local fixtures do not establish real-provider behavior
or runtime acceptance on other platforms.

Before publication, release automation builds and tests Linux x64/arm64,
macOS x64/arm64 and Windows x64/arm64, including npm startup, native offline
startup without Node/npm, shared-data checks and npm/native payload parity.
