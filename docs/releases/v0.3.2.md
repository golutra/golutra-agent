## Golutra Agent 0.3.2

This release improves continuous task execution, connection recovery and tool
reliability while preserving the model's control over how to complete a task.

### Install or update

```sh
npm install -g @golutra/agent@0.3.2
golutra-agent --version
golutra-agent
```

### Continuous execution

- Tasks have no implicit time, tool-call, cost, correction-round or no-progress
  cutoff. User cancellation, explicitly configured budgets and permissions remain
  effective.
- Recoverable connection outages wait and continue the same logical request.
  Background processes can keep running during recovery. Authentication errors,
  invalid requests and HTTP failures retain separate, bounded error handling.
- Provider adapters share completion and recovery handling; incomplete model
  responses do not silently become successful task completion.
- Compaction and resume retain original requirements, subsequent user input and
  tool-call/result relationships. Recovery state is visible in the terminal.

### Fewer unnecessary correction rounds

- Correction feedback includes the actual failed operation and relevant output.
  Recovered failures and stale exploration no longer become permanent obligations.
- Validation distinguishes source edits from verified source-derived cache
  changes, and preserves valid evidence when only such caches changed.
- Compound Shell commands have consistent validation semantics with or without
  explicit Shell wrapping. Checks retain their directory and Shell context;
  masked failures and background launches do not count as completed validation.
- A patch may delete and then add the same exact path as one atomic replacement.
  Existing batch validation, collision checks and file permissions are retained.

### Distribution and validation

The npm launcher and six native platform packages share version 0.3.2. Windows,
macOS and Linux x64/ARM64 packages reuse the same native payloads as desktop
archives, with release inventories and checksums. Bundled desktop execution does
not require Node.js or npm; npm installations still use the npm launcher.

Regression coverage includes real processes, provider streams, connection
recovery, repeated compaction, correction and atomic patch application. The final
validation/tool suites passed 440 Rust tests and the benchmark suites passed 82
Python tests before the version bump; a real 120-second TCP connection-outage
test passed separately. Release jobs additionally require native execution,
npm installation and shared-data acceptance on each target before publication.

All 24 recent coding comparison attempts are retained, including failures and
slower samples. The final four-stage comparison passed for both engines, taking
139.09 seconds for Golutra and 192.92 seconds for Codex with the same requested
model and reasoning level. Earlier cross-domain timing was effectively tied.
These macOS/Responses, minute-scale results do not establish universal or
multi-hour superiority, or validate every live provider protocol.

This release does not change the installation/data namespace or storage schema.
Existing restrictions on obsolete data and ownership of a running session remain.
Desktop bundles update with their desktop application; npm manages npm installs.
