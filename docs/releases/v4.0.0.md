## Golutra Agent 4.0.0

This release adds browser control and unifies subagents with durable background
work, with explicit permissions, reliable result delivery and clearer terminal
connection states.

### Install or update

Requires Node.js 20.18.1 or newer.

```sh
npm install -g @golutra/agent@4.0.0
golutra-agent --version
golutra-agent
```

### Browser control

- `/connect` discovers and checks a browser. Automatic selection prefers Ego,
  then Chrome, and offers Ego installation with consent if neither is installed.
  An explicit saved browser selection is preserved.
- Ego uses its native SDK; Chrome uses the official OpenCLI extension and the
  OpenCLI 2.0.3 dependency included with the npm launcher. Both use existing user
  profiles. Chrome still requires the official extension; Ego first-run setup
  remains a user action. The Ego application is not bundled in the npm package.
- Agents can inspect or change the session's backend selection while active
  tasks retain their original binding. Connection readiness, launch requests,
  installation requirements and cancellation are reported separately.
- Connection summaries show user-facing status; detailed diagnostics remain
  available without exposing tool instructions in normal output.

### Subagents and background tasks

- Background operations and children share durable batches and result inboxes.
  Completed results can join an existing inference request; user input takes
  priority, and pause, cancellation or handoff does not grant an automatic resume.
- Same-session continuation, queued messages, task/question attribution and
  `/agents` controls preserve execution identity across asynchronous work.
- Child tool profiles can only retain or narrow inherited permissions.
  Assignments describe owned files, interfaces, checks and acceptance criteria.
  Owned paths are delivery responsibilities, not a filesystem sandbox.
- Batch output retains short answers and failure facts while long results use
  explicit continuation ranges. Partial findings are not acknowledged as fully
  read. Final answers wait for pending results and verification to be reconciled.
- Natural-language acceptance remains explicitly pending parent review;
  file existence alone does not prove behavior. Runtime file and process evidence
  checks remain in place.
- Resource waits, queue time and execution time are recorded for diagnosis.
  Browser operations retain conservative serialization.

### Data compatibility

This version uses data schema 9. Exact supported schema 7 or 8 stores upgrade
transactionally when opened, retaining sessions and existing data. Unknown,
modified or unsupported older schemas remain rejected without resetting data.

Stop older instances sharing the Agent home before upgrading. After the upgrade,
readers supporting only schema 7 or 8 cannot open that store: update the runtime
embedded in desktop applications as well as the npm installation. Do not use a
package downgrade as a database rollback. See the
[shared-data contract](https://github.com/golutra/golutra-agent/blob/v4.0.0/docs/shared-data-compatibility.md).

### Validation and distribution

The 4.0.0 release candidate passed 2,374 Rust tests across 59 targets, with 11
explicit skips, and strict workspace Clippy. Release preparation also passed 39
packaging tests, 10 browser/launcher tests, 9 TypeScript SDK tests, 14 Python SDK
tests, protocol generation checks and a TypeScript dependency audit with zero
reported vulnerabilities. Four real-provider game runs at
4/8/8/4 concurrency completed all 32 children and acknowledged all results. Every
original game passed 23 logic checks and 15 real-browser behavior checks. Manual
visual review passed in three of four originals; the remaining narrow-layout
defect was fixed and verified in a separate copy, outside generation timing.

The game samples used macOS arm64 and grok-4.7 low, with only two samples per
concurrency setting. They do not establish an optimal default or long-duration
reliability. Original failures and measurements remain in the
[validation report](https://github.com/golutra/golutra-agent/blob/v4.0.0/docs/subagent-delivery-refactor-2026-11-17.md).

The release workflow builds and validates Linux, macOS and Windows x64/arm64
native archives and npm payloads before publishing all seven npm packages with
matching 4.0.0 versions. SDK metadata is aligned; the TypeScript SDK remains
private and is not published as a new public package.
