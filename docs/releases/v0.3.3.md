## Golutra Agent 0.3.3

This release improves terminal responsiveness, streaming display and provider
setup, including model discovery that never blocks manual model entry.

### Install or update

```sh
npm install -g @golutra/agent@0.3.3
golutra-agent --version
golutra-agent
```

### Provider setup

- Golutra API and Custom Provider show a blank manual model option first.
  Type or paste a model ID and continue immediately. Models fetched from the
  upstream service appear below the manual option and can be selected with
  Up/Down and Enter. Results do not change focus or overwrite input.
- Discovery supports OpenAI Chat Completions/Responses, Anthropic and Gemini
  catalogs, with protocol-specific URLs and authentication. Requests have a
  10-second limit; errors and empty lists leave manual entry available.
  Vertex AI and rust-genai currently use manual entry. Catalogs are read as a
  single response without following pagination; discovery is not a guarantee
  that a model supports the chosen protocol or generation settings.
- API keys default to local owner-only credential storage. Ctrl+E switches to
  an existing environment-variable reference; users enter the variable name
  explicitly instead of receiving an automatically generated name.
- Advanced settings default to Continue. Select another setting to cycle or
  edit it with the keyboard. Review and save remain local operations and do
  not require a network validation request.

### Terminal interaction

- Improve typing and streaming responsiveness through bounded event processing,
  incremental transcript updates and cached rendering work.
- Reduce redundant redraws and repeated long-history rendering while preserving
  streaming content, drafts and native terminal text selection.

### Distribution and validation

The npm launcher and six native platform packages share version 0.3.3. Windows,
macOS and Linux x64/ARM64 artifacts reuse the same native CLI/TUI payloads for
npm and desktop distribution. Native desktop startup does not require Node.js
or npm; release inventories provide pinned URLs and checksums.

Before the version bump, 475 provider-catalog and TUI tests passed, including
local HTTP fixtures and real PTY tests. Clippy with warnings denied and format
checks passed. One live-provider smoke test was skipped; no real account keys
were used to validate upstream model discovery. Release jobs additionally gate
publication on native execution, npm installation, payload parity and
shared-data acceptance on all six supported targets. These checks do not
replace desktop signing or testing every terminal and minimum OS version.

This release does not change the Agent data namespace or storage schema.
Desktop bundles update with the desktop application; npm manages npm installs.

See the [changelog](https://github.com/golutra/golutra-agent/blob/v0.3.3/CHANGELOG.md)
and [desktop integration guide](https://github.com/golutra/golutra-agent/blob/v0.3.3/docs/desktop-integration.md).
