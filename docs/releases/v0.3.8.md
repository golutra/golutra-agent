## Golutra Agent 0.3.8

This release tightens session recovery and keeps runtime diagnostics in the
explicit `/debug` surface.

### Install or update

```sh
npm install -g @golutra/agent@0.3.8
golutra-agent --version
golutra-agent
```

### Changes

- `/resume` and `/export` show catalog information and timestamps without
  exposing status, verification or model facts from runtime events.
- Asynchronous resume results are bound to the selected thread. Stale results
  are discarded after selection changes or cancellation.
- Double-Esc history editing validates its original thread/session before and
  after the asynchronous fork preparation.
- `/resume` and `/export` share the same session-row projection and branch
  markers. The currently attached session cannot be archived or deleted.
- Export no longer performs one event-page request for every session.

### Distribution and validation

The npm launcher, six platform packages, native archives and SDK metadata share
version 0.3.8. No user-data format changes are included.

Local validation passed the complete TUI, client, store and app-server test
suites, Clippy with warnings denied, formatting checks and `git diff --check`.

Release automation builds and validates Linux x64/arm64, macOS x64/arm64 and
Windows x64/arm64 artifacts before publishing the npm packages.

See the [changelog](https://github.com/golutra/golutra-agent/blob/v0.3.8/CHANGELOG.md).
