## Golutra Agent 0.3.9

This patch release improves background-task validation, response recovery and
failure diagnostics.

### Install or update

```sh
npm install -g @golutra/agent@0.3.9
golutra-agent --version
golutra-agent
```

### Changes

- Background commands are validated using their final process state and complete
  evidence. Test summaries split across consecutive reads are recognized, and
  successful reruns recover the corresponding earlier failures.
- Useful tool calls reset consecutive empty-response counts. Non-final Responses
  continuations use a separate bounded guard rather than the empty-final path.
- Final failures retain their actual runtime cause and relevant evidence in both
  streamed and stored events. Terminal status distinguishes unknown validation
  from failure and replaces stale running markers when a process exits.
- Responses preserves tool arguments supplied in terminal events and records
  bounded stream metadata without message bodies, arguments or credentials.
- Unreported retry usage remains unknown; known totals are not presented as the
  complete cost of all attempts.
- Sandboxed patch execution on macOS resolves the real Git executable before
  entering the sandbox, avoiding Apple shim cache-write failures.
- `/status` includes task and build identity to help identify older executables.

### Validation and distribution

The implementation passed 2,193 workspace tests (four explicit skips), strict
Clippy, formatting and release builds. Twelve controlled-provider CLI scenarios
matched their expected outcomes, including negative cases. The original training
workspace passed training, four unit tests and dependency checks.

These controlled tests do not establish that upstream empty responses or service
outages cannot recur. New diagnostics make future failures easier to investigate.

The npm launcher, six platform packages, native archives and SDK metadata share
version 0.3.9. Release automation validates Linux, macOS and Windows x64/arm64
artifacts before publishing. User-data format versions are unchanged.

See the [changelog](https://github.com/golutra/golutra-agent/blob/v0.3.9/CHANGELOG.md).
