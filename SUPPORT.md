# Support

Golutra Agent is an early open-source project. Community support is best
effort and there is no guaranteed response time.

Use the right channel:

| Need | Channel |
| --- | --- |
| Reproducible bug | [Bug report](https://github.com/golutra/golutra-agent/issues/new?template=bug_report.yml) |
| Proposed capability | [Feature request](https://github.com/golutra/golutra-agent/issues/new?template=feature_request.yml) |
| Design or usage question | [GitHub Discussions](https://github.com/golutra/golutra-agent/discussions) or an issue |
| Security vulnerability | [SECURITY.md](SECURITY.md), never a public issue |

Before opening a request:

1. Check the [README](README.md), [documentation index](docs/README.md), and
   existing issues.
2. Record the Golutra commit or release, operating system, Rust/Node/Python
   versions, and the smallest reproducible command.
3. Remove credentials, private workspace data, and unredacted provider or
   runtime artifacts from logs.

Questions about a local integration are easier to answer when the command,
expected behavior, actual behavior, and a redacted trace are included.
