Chrome is controlled by OpenCLI 2.0.3 and its official Chrome extension. Ego uses its own native SDK: keep the OpenCLI extension disabled in Ego to avoid connection conflicts and repeated reconnects. Automatic selection prefers installed Ego, then Chrome. If neither is installed, ask for consent before downloading/installing Ego with golutra-agent browser install-ego --yes. Explicit backend selection takes priority; never switch after an error or replay uncertain actions.
browser_config reads or sets this session's browser_backend (auto/ego/chrome). Check resolved_backend and switch_pending: active tasks stay bound until explicit release; choice never changes the global Profile or another session. Read help again after switching. browser_launch opens normal Chrome; browser_status checks connection without creating pages. Missing OpenCLI/extension is setup_required, not success. Profile selection is pinned per Golutra session. Workspaces and sessions receive distinct OpenCLI session names; do not bind arbitrary existing private tabs.
browser_run accepts one structured action:
open(url): begin a new task page, http/https only, using existing Chrome login state. navigate(url): navigate the active task. Finish before another open.
snapshot: DOM snapshot and page diagnostics; use its CSS selectors or numeric refs for click/hover/fill/type/select. Re-observe after navigation or stale refs.
click/hover(selector, optional nth): use a unique observed selector or zero-based index in an observed match list, never guess. Typed target-resolution rejection is known not to dispatch the click/hover; correct the target directly. Other failures may still require observation. fill/type(selector,text); select(selector,text option); press(key); scroll(y signed vertical pixel count); back.
frames: list cross-origin frames. evaluate(expression, optional frame_index from frames) runs page JavaScript, not Node. No arbitrary CLI commands or profile/session overrides.
wait(kind:selector|text|download,text): wait for a target, text, or download name/URL. For downloads click the actual download link then wait; no fabricated local file path.
screenshot: actual PNG image returned to model. upload(selector,files absolute paths): attach files via the browser.
browser_handoff pauses Golutra actions and keeps the page; OpenCLI's debugger may remain attached. Resume only after the user confirms, via resume_after_user:true. Cancellation stops the CLI but an already dispatched browser action may finish; observe before further changes.
browser_finish by default shows the original result page in the foreground and pauses agent actions. It keeps the lease/debugger, not a permanent detached tab: OpenCLI may recycle it after about 10 minutes idle. Save screenshots/results and tell the user the page remains available temporarily. Resume browser_run only after user confirmation via resume_after_user:true. Use browser_finish(release:true) only when cleanup is requested; acknowledged unbind may recycle/close this task's page, never unrelated user tabs. Release before opening another task in this session.
No additional retry is performed by Golutra. OpenCLI has its own command journal; unknown results must be inspected before mutation. This is not an exactly-once guarantee across crashes or arbitrary shell invocations.
